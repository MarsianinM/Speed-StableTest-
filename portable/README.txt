SpetTest — замір швидкості та стабільності інтернету
====================================================

Портативна програма для Windows 10/11. Нічого встановлювати не потрібно.

Що копіювати на флешку
----------------------
  Після збірки (.\scripts\build.ps1) беріть папку:

    dist\SpetTest\

  Скопіюйте на флешку (або диск) УСЮ цю папку цілком, разом із:
    SpetTest.exe
    _internal\          (обов’язково, без неї програма не запуститься)
    Інтерфейс.cmd
    Швидкість.cmd
    Стабільність.cmd
    README.txt

  Не копіюйте лише один .exe і не беріть папки build\ або portable\
  з репозиторію — робочий комплект саме dist\SpetTest\.

Що запускати
------------
  Інтерфейс.cmd       — вікно (темна тема): тести, простий прогрес, історія
  Швидкість.cmd       — консольний замір Download / Upload / Ping
  Стабільність.cmd    — консольна перевірка затримки / джиттера / втрат (~60 с)

У вікні стабільність завжди 60 с. Історія зберігається локально у файлі
spettest.db поруч із програмою (без синхронізації між копіями).

Під час тесту у GUI видно етап і простий прогрес-бар (не клон speedtest.net).

Після тесту програма підказує придатність для: відеодзвінок, стрім,
перегляд відео, онлайн-гра, скачування. Ping (HTTPS) — лише попередження,
не заборона (він завищений порівняно з ICMP / ігровим).

Якщо Windows показує «Windows захистив ваш ПК»
---------------------------------------------
Це нормально для програми без цифрового підпису.
Натисніть «Докладніше» → «Виконати попри це».

Вимоги
------
  • Windows 10 або 11 (64-bit)
  • Інтернет під час тесту
  • Права адміністратора НЕ потрібні

Поради
------
  • Під час тесту краще не качати інші великі файли і не вмикати VPN,
    якщо хочете цифри ближчі до реального каналу.
  • Результат залежить від Wi‑Fi, навантаження мережі та серверів тесту.
  • Літера диска флешки може бути будь-якою (E:, F: …) — ярлики це враховують.
  • Download/Upload близькі до speedtest.net, але не ідентичні.
    Ping через HTTPS, тому вищий за ICMP у Ookla.

Що означає «Стабільність»
-------------------------
Це перевірка якості відгуку мережі (ping, джиттер, втрати спроб),
а не довгий замір швидкості качання.

Версія: 0.2 (CLI + GUI)
